# Observatório de Streptococcus · Página de lançamento

Página única (`index.html`, autossuficiente) para captar contatos de quem tem interesse no lançamento do Observatório de Streptococcus (LCPM/UFRJ). Bilíngue (PT/EN), com identidade visual do manual da marca.

## Publicação no Netlify
1. Conecte este repositório ao Netlify (ou arraste o `index.html`).
2. Ative a detecção de formulários (Forms). O formulário `lancamento` é detectado automaticamente.
3. Os cadastros ficam em Forms › lancamento e podem ser exportados em CSV.

Parâmetro opcional de idioma: `?lang=pt` ou `?lang=en`.

Campos: nome, e-mail, instituição/organização (opcional) e consentimento (LGPD).
